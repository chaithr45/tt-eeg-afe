# Low-noise neonatal EEG front-end (Tiny Tapeout, SKY130)

A capacitive-feedback biopotential amplifier for neonatal EEG, designed for the Tiny Tapeout TTSKY26d shuttle (SkyWater SKY130, 1x2 analog tile, 2 analog pins). It is the analog front-end for an FPGA neonatal-seizure detector.

**Status:** schematic, layout and post-layout verification done. The layout is DRC clean, matches the schematic in LVS (core and full tile) and passes the Tiny Tapeout precheck. Simulated with its extracted parasitics it matches the schematic within 0.05 dB of gain at every corner.

| | Schematic | Layout (extracted) |
|---|---|---|
| Midband gain | 37.79 dB (77.5 V/V), set by C1/C2 = 11.9 pF / 154 fF | 37.75–37.76 dB, all corners |
| Band | high-pass < 0.5 Hz (pseudo-resistor), low-pass 18–22 kHz | same |
| Input-referred noise, 0.5–100 Hz | 2.9–3.1 µVrms | 2.89–3.11 µVrms |
| Supply | 1.8 V, 12–16 µA (22–28 µW) | same |
| PSRR at 50 Hz | 90–103 dB | 81–91 dB |
| Mismatch (200 Monte Carlo samples) | gain σ = 0.06 %, output offset σ = 0.26 mV | |
| Reset | `ui_in[0]` high for 10 ms: settles after power-up or an electrode artifact | output step at release ≈ 1 mV |
| Temperature range | 0–50 °C | |

Ranges cover both SKY130 model sets (original binned and newer continuous) and the five process corners at 27 °C, plus 0 °C and 50 °C. Details: [design/README.md](design/README.md) §1 and §9.

## Pins

| Pin | Function |
|---|---|
| `ua[0]` | EEG input (AC-coupled on chip) |
| `ua[1]` | Amplified output, DC level ≈ 0.45 V |
| `ui_in[0]` | `rst`, active high |
| `VDPWR`, `VGND` | 1.8 V supply, ground |

## Reproducing

Inside the [IIC-OSIC-TOOLS](https://github.com/iic-jku/IIC-OSIC-TOOLS) container:

```
sak-pdk sky130A
cd design/sim
python3 run_all.py --quick                      # schematic, original SKY130 models
SKY130_LIB=combined python3 run_all.py --quick  # schematic, newer continuous models
python3 tb_mc.py                                # Monte Carlo
cd ../../layout && python3 build.py             # layout: DRC, LVS, GDS/LEF, extraction
cd ../design/sim && python3 tb_postlayout.py    # extracted layout against the schematic
cd ../xschem && xschem tb_eeg_afe.sch           # GUI testbench: Netlist, then Simulate
```

## About Tiny Tapeout

[Tiny Tapeout](https://tinytapeout.com) is an educational project that makes it cheap to get designs manufactured on a real chip. Analog specifications: [tinytapeout.com/specs/analog](https://tinytapeout.com/specs/analog/).
