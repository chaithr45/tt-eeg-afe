# Low-noise neonatal EEG front-end (Tiny Tapeout, SKY130)

A capacitive-feedback biopotential amplifier for neonatal EEG, designed for the Tiny Tapeout TTSKY26d shuttle (SkyWater SKY130, 1x2 analog tile, 2 analog pins). It is the analog front-end for an FPGA neonatal-seizure detector.

**Status:** schematic and pre-layout verification done (corners, Monte Carlo, start-up, both SKY130 model sets). Layout in progress.

| | Simulated (pre-layout) |
|---|---|
| Midband gain | 37.8 dB (77.5 V/V), set by C1/C2 = 11.9 pF / 154 fF |
| Band | high-pass < 0.5 Hz (pseudo-resistor), low-pass 18–22 kHz |
| Input-referred noise, 0.5–100 Hz | 2.9–3.1 µVrms |
| Supply | 1.8 V, 12–16 µA (22–28 µW) |
| PSRR at 50 Hz | 91–97 dB |
| Mismatch (200 Monte Carlo samples) | gain σ = 0.06 %, output offset σ = 0.26 mV |
| Reset | `ui_in[0]` high for 10 ms: settles after power-up or an electrode artifact |
| Temperature range | 0–50 °C |

![Simulated closed-loop gain](docs/gain.png)

## Pins

| Pin | Function |
|---|---|
| `ua[0]` | EEG input (AC-coupled on chip) |
| `ua[1]` | Amplified output, DC level ≈ 0.45 V |
| `ui_in[0]` | `rst`, active high |
| `VDPWR`, `VGND` | 1.8 V supply, ground |

## Reproducing the simulations

Inside the [IIC-OSIC-TOOLS](https://github.com/iic-jku/IIC-OSIC-TOOLS) container:

```
sak-pdk sky130A
cd design/sim
python3 run_all.py --quick                      # original SKY130 models
SKY130_LIB=combined python3 run_all.py --quick  # newer continuous models
python3 tb_mc.py                                # Monte Carlo
cd ../xschem && xschem tb_eeg_afe.sch           # GUI testbench: Netlist, then Simulate
```
